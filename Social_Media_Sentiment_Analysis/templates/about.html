Social Media Sentiment Analysis

This application explores social posts grouped by entity and sentiment, and classifies new text using a machine-learning pipeline.

INPUT DATACSV · text + labels

Reads the original headerless dataset with explicit columns.

FEATURE EXTRACTIONTF-IDF n-grams

Turns words and short phrases into numerical features.

CLASSIFIERLogistic Regression

A saved scikit-learn Pipeline is used for both training and prediction.

EVALUATIONHeld-out test set

Accuracy, macro precision/recall/F1 and class-level report.

Dataset limitation

The supplied CSV has no date column, so this version does not display a fabricated sentiment-over-time chart. A real trend chart requires trustworthy timestamps.
